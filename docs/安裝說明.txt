============================================================
  Riot Account Hub —— VALORANT / Riot 帳號切換器
  安裝說明
============================================================

這是什麼？
  每個 Riot 帳號只要登入一次，之後在這個程式按一下「啟動」，
  就會自動切換到那個帳號並打開 VALORANT，不用每次重新登入。
  （Google、Facebook、Apple、帳號密碼登入都可以用）

  ※ 這不是 Riot Games 官方的程式。


------------------------------------------------------------
一、需要什麼
------------------------------------------------------------
  - Windows 10 或 Windows 11（64 位元）
  - 已經安裝好 Riot Client 和 VALORANT
  - 不需要另外安裝其他東西（程式已經把需要的都包在一起了）


------------------------------------------------------------
二、安裝步驟
------------------------------------------------------------
  1. 先解壓縮
     在下載的 zip 檔上按右鍵 →「全部解壓縮」→「解壓縮」。
     ※ 不要直接在 zip 裡面雙擊執行，資料可能存不起來。

  2. 把程式放到一個固定的地方
     把「RiotAccountHub.exe」移到你不會亂刪的資料夾，
     例如「文件」裡新建一個「Riot Account Hub」資料夾。
     （之後不要再搬動它，不然開機自動開啟會找不到）

  3. 雙擊「RiotAccountHub.exe」開啟

     如果跳出藍色的「Windows 已保護您的電腦」：
       按「其他資訊」→「仍要執行」。
     這是因為這個程式沒有購買微軟的付費數位簽章，不是病毒。
     第一次按過之後就不會再跳。

  4.（建議）建立捷徑，方便以後打開
     程式開著的時候，在工作列的圖示上按右鍵 →「釘選到工作列」。
     或是在 exe 上按右鍵 →「顯示其他選項」→「傳送到」→「桌面（建立捷徑）」。


------------------------------------------------------------
三、第一次使用：把帳號加進來
------------------------------------------------------------
  1. 按右上角的「新增帳號」
     程式會先關閉 Riot Client，然後幫你重新打開登入畫面。

  2. 在 Riot Client 用要加入的帳號登入
     ★ 登入時一定要勾選「保持登入」★
     沒勾的話，之後沒辦法自動登入。

  3. 看到 Riot Client 主畫面後，回到程式按「我登入好了」
     程式會自動抓到你的 Riot ID，選好登入方式後按「儲存」。

  4. 其他帳號重複 1～3 步。

  之後只要在帳號卡片上按「啟動」，就會切換帳號並打開遊戲。


------------------------------------------------------------
四、其他功能（都在首頁）
------------------------------------------------------------
  - 段位與卡面：用這個程式玩過一次後，卡片會顯示段位和遊戲卡面
  - 複製設定 / 套用設定：把一個帳號的鍵位、靈敏度、準星複製到另一個帳號
  - 主帳號：設定後，其他帳號可以一鍵「套用主帳號」的設定
  - 戰績：用程式內的瀏覽器打開這個帳號在 Valorant Tracker 的頁面
  - 熱門準星：瀏覽 VCRDB 網站、收藏和複製準星代碼
  - 關閉遊戲：卡片上的按鈕顯示「遊戲中」時再按一下，確認後就會關掉 VALORANT
  - 開機時自動開啟、按啟動後自動開始遊戲：在畫面最下面可以開關


------------------------------------------------------------
五、安全嗎？
------------------------------------------------------------
  - 不會儲存你的密碼。只存 Riot Client 自己產生的「保持登入」檔案。
  - 存下來的登入資料都用 Windows 內建的加密（DPAPI）保護，
    只有「這台電腦 + 這個 Windows 帳號」解得開，複製到別台電腦也沒用。
  - 不會讀取或修改遊戲的記憶體，不會修改任何 Riot 的程式檔案，
    也不會碰 Vanguard（反作弊）。
  - 所有資料都存在你自己的電腦：
      %AppData%\RiotAccountHub
    （在檔案總管上方的網址列貼上這一行就能打開）

  這種「切換登入檔案」的做法跟知名的開源工具 TcNo Account Switcher 相同。
  不過它畢竟不是 Riot 官方的程式，請自行斟酌使用。


------------------------------------------------------------
六、常見問題
------------------------------------------------------------
  Q：畫面下面寫「找不到 Riot Client」？
  A：按旁邊的「變更」，選擇 RiotClientServices.exe。
     通常在：C:\Riot Games\Riot Client\RiotClientServices.exe

  Q：切換之後 Riot Client 又要我登入？
  A：可能是當初沒勾「保持登入」、登入狀態過期了，
     或是在 Riot Client / 遊戲裡按過「登出」（登出會讓存起來的登入作廢）。
     程式發現時會跳出提醒，卡片上也會顯示黃色的「登入已失效」，按「重新登入」再登入一次就好；
     也可以自己在那個帳號的卡片上按「重新登入」（循環箭頭圖示）。
     ※ 想關遊戲或換帳號，直接用這個程式就好，不要按 Riot 的「登出」。

  Q：想回到用這個程式之前的狀態？
  A：按首頁上方的「還原原本狀態」。

  Q：按「戰績」後看不到資料？
  A：第一次打開 Valorant Tracker 時，網站會先跳出「Human Check」驗證，點一下就好。
     如果顯示「私人」，要在 Valorant Tracker 網站用那個 Riot 帳號登入一次，
     把戰績設成公開。

  Q：防毒軟體說它有問題？
  A：沒有付費數位簽章的新程式，有時候會被防毒軟體誤判。
     如果你不放心，可以不要使用。


------------------------------------------------------------
七、更新到新版本
------------------------------------------------------------
  v1.0.4 以後的版本：
    程式上方出現「有新版本」時，按「立即更新」就好
    （也可以在畫面最下面按「檢查更新」）。
    程式會自己下載、換成新版、重新開啟。

  v1.0.3 以前的舊版（只要做這一次）：
    1. 到下載頁面下載「更新包」RiotAccountHub-update-v版本.zip，解壓縮
    2. 先打開舊版的 Riot Account Hub
    3. 再雙擊更新包裡的 RiotAccountHub.exe，按「更新」
    之後的更新就能直接在程式裡按「立即更新」了。

  你的帳號和設定都存在 %AppData%\RiotAccountHub，不會因為更新而消失。


------------------------------------------------------------
八、移除
------------------------------------------------------------
  1. 如果有開「開機時自動開啟」，先在程式最下面把它關掉
  2.（選擇性）按「還原原本狀態」，把 Riot Client 放回最初的登入狀態
  3. 關掉程式，刪除 RiotAccountHub.exe
  4.（選擇性）想連資料一起刪：
     在檔案總管網址列貼上 %AppData%\RiotAccountHub，刪除整個資料夾
